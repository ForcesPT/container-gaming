# Selected Epic game observations (local candidate)

October 3, 2026. The helper emits only schema, selected release ID, running-game
boolean/null and update-hint boolean/null. It reads the sealed selected binding
and official capsule, exact matching processes and one selected installation
record. It does not read client logs, credentials, tokens or save contents.

Matching requires this user's UID, managed Epic prefix/marker and selected
executable path. Unreadable candidates are unknown, not proof of game exit.
Changed public installation version is an unconfirmed hint for a trusted storage
check. An unchanged record cannot prove that no mandatory store update exists.

Eight offline non-root Linux cases pass, including a real disposable /proc
process, unrelated prefix/user/game rejection, private-record redirects and
unknown/quiet-period handling. This is not gameplay, cloud-sync or native media
acceptance. The worker requires an explicit qualified image allowlist, default
empty; no production activation is implied by copying the helper into the image.

`Dockerfile.instant-observation` creates an account-free local derivative of the
reviewed overlay-recovery candidate. Both maintained Epic Instant Dockerfiles
package the helper for future complete builds. No Compute behavior changes.

Before enabling observations for a real game, qualify its process path on the
exact runtime. Games with differently named launcher/child executables require
an explicit supported contract; observing the wrong process is insufficient.
Play again and graceful cloud-sync shutdown are separate capabilities.
